# 🚗 8891 中古車快速查詢與智慧估價系統

一套基於 **Python Tkinter GUI** 與 **SQLite 資料庫** 的中古車資料檢索與市場行情分析桌面軟體。系統內建收錄自 8891 平台的近 4 萬筆車源大數據，提供直覺的多維度車源篩選、表格檢視，以及基於大數據統計的「二手車行情智慧估價」功能。

## 🌟 系統特色

1. **多維度車源篩選**
   - 支援依**全台縣市**下拉選單快速篩選。
   - 支援車輛標題與品牌型號**模糊關鍵字**搜尋（不區分大小寫）。
   - 一鍵「顯示全部」重置篩選狀態。

2. **清爽直覺的清單檢視**
   - 採用 `Treeview` 結構化呈現：所在縣市、完整標題、出廠年份、行駛里程、售價。
   - 內建垂直捲軸滾動支援，狀態列即時反饋搜尋筆數與載入狀態。

3. **大數據行情智慧估價**
   - 輸入車款關鍵字（如 `Altis`、`RAV4`、`C300`）與出廠年份。
   - 支援輸入「預計行駛里程」，系統自動比對市場同型車平均里程，給出「里程高/低於均值」之修正提示。
   - 自動運算並產生詳細報告：**參考樣本數**、**市場平均行情價**、**合理開價區間（最低~最高價）**、以及**買賣建議議價空間（-5% ~ -10%）**。

4. **一鍵 CSV 匯出與報表儲存**
   - **智慧估價報告匯出**：一鍵將估價結果摘要（行情均價、開價區間、里程分析）與全部參考車源樣本明細匯出為 CSV 檔。
   - **車源清單匯出**：支援將當前查詢與篩選後的車輛資料整批匯出為 CSV。
   - **Excel 零亂碼**：採用標準 `utf-8-sig`（帶 BOM）編碼，在 Windows Excel 中開啟中文完全不亂碼。

5. **熱重載與例外容錯**
   - 頂部設有「🔄 重新載入資料庫」按鈕，若資料庫有更新或重新爬取，無需重啟視窗即可直接讀取最新車況。
   - 完善的異常攔截與友善彈跳視窗（MessageBox）錯誤提示。

## 🛠️ 環境需求與安裝

### 1. Python 版本
- 建議使用 **Python 3.8** 或以上版本（支援 Windows / macOS / Linux）。

### 2. 安裝必要依賴
本專案 GUI 使用 Python 內建的 `tkinter`，資料庫使用內建的 `sqlite3`。僅需安裝資料處理套件 `pandas`：

```bash
pip install pandas
```

> **Windows 備註**：官方標準安裝的 Python 通常已內建 Tkinter。若使用 Linux，如遇 Tkinter 缺失可透過套件管理器安裝（例如 Ubuntu：`sudo apt-get install python3-tk`）。

## 📖 功能操作說明

### 1. 車源快速查詢
- 點選切換至 **「🔍 車源快速查詢」** 分頁。
- **縣市篩選**：從下拉選單選擇特定縣市（例如「新北市」），預設為「全部縣市」。
- **關鍵字搜尋**：在輸入框輸入車款、品牌或規格關鍵字（例如 `CR-V`、`Focus`、`油電`），按下 **「查詢」**。
- **查看結果**：下方表格將即時更新符合條件的車輛列表，底部的狀態列會顯示當前符合筆數。
- **恢復顯示**：點擊 **「顯示全部」** 即可清除搜尋條件並重置所有列表。
- **匯出 CSV**：點擊 **「💾 匯出車源 (CSV)」** 按鈕，即可自訂路徑儲存當前篩選/顯示的車源清單。

### 2. AI 智慧估價系統
- 點選切換至 **「💰 AI 智慧估價系統」** 分頁。
- **車款關鍵字**：輸入欲估價的品牌或型號（例如 `RAV4`、`Altis`、`C300`）。
- **出廠年份**：輸入西元年份（例如 `2019`）。
- **預計行駛里程（選填）**：輸入目標公里數（例如 `65000`）。
- 點選 **「🚀 開始智慧估價與市場行情分析」** 按鈕。
- **報告產出**：
  - **參考樣本數**：統計資料庫內符合該型號與年份的車源總量。
  - **市場平均行情價**：以全體符合車源之平均價計算。
  - **合理開價區間**：呈現市場最低與最高價格分佈。
  - **里程修正提示**：若有輸入里程，系統將比對市場平均值並提示偏高或偏低狀況。
  - **建議議價空間**：提供業界建議折讓空間（-5% ~ -10%）。
- **儲存估價報告 (CSV)**：
  - 估價完成後，點擊綠色的 **「💾 儲存估價報告 (CSV)」** 按鈕。
  - 系統彈出檔案儲存視窗，可自由選擇儲存位置與檔名。
  - 產出的 CSV 包含兩大區塊：**上方為估價報告摘要指標**（均價、區間、折讓、時間等），**下方為本次計算參考的全部車源明細**（縣市、標題、年份、里程、售價、車輛連結）。

### 3. 即時資料重載
- 視窗右上角設有 **「🔄 重新載入資料庫」** 按鈕。
- 當底層的 `auto8891.db` 有被更新或替換時，點擊此按鈕即可免重啟快速重新載入。

## ⚙️ 核心演算法與設計細節

### 1. 數值清洗機制 (`to_number`)
由於爬取的原始字串包含中文單位（如「`52.8萬`」、「`6.5萬公里`」），程式使用正則表達式進行結構化轉換：
- 抽取數值與小數點。
- 遇「萬」單位則自動乘以 10,000，將字串正規化為標準整數，以便進行高效率的 Pandas 數值統計與均值計算。

### 2. 估價分析邏輯 (`calculate_valuation`)
- **兩階段篩選**：先以字串比對命中車款標題，再篩選符合年份之車源，並過濾掉無效開價（價格 $\le 0$）。
- **里程偏移率**：計算 $Target\_KM - Mean(DB\_KM)$，輔助評估該車輛是否為低里程優質車或高里程用車。

## ❓ 常見問題 (FAQ)

**Q1：啟動時跳出「讀取資料庫失敗」錯誤？**
- 請確認 `auto8891.db` 與 `auto8891_app.py` 是否放置在同一個資料夾目錄下。

**Q2：搜尋某個車款卻估不出價格？**
- 可能是關鍵字過於冗長或年份無匹配資料。建議簡化關鍵字（例如搜尋 `Altis` 而非 `Toyota Corolla Altis 豪華版`）。

**Q3：字體在高解析度 (4K / 2K) 螢幕下可能有些模糊？**
- 此為 Windows 下 Tkinter 未宣告 DPI 感知（DPI Awareness）的常見現象，軟體內已將基礎字體設為 10pt/11pt 微軟正黑體（Microsoft JhengHei），日常使用清晰易讀。
